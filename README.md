# DMS Plumbing Website
[DMS Original web inspo.zip](https://github.com/user-attachments/files/31680123/DMS.Original.web.inspo.zip)

## Project Overview

This project is a website developed for DMS Plumbing. The purpose of the website is to provide users with clear information about the company, its plumbing services, contact details and enquiry options.

The website was designed using a simple and structured HTML approach. The initial development focuses on the HTML structure and functionality before visual styling and JavaScript are added.

## Organisation

DMS Plumbing is an owner-managed plumbing company that was established in 1999. The company provides plumbing services to residential, commercial, retail and hospitality customers.

DMS Plumbing also provides emergency plumbing services 24 hours a day, 7 days a week.

## Website Pages

The website consists of five main pages:

1. Home
2. About Us
3. Services
4. Enquiry
5. Contact

### Home Page

File: index.html

The Home page introduces DMS Plumbing and provides basic information about the company and its emergency plumbing services. It also contains a call-to-action that directs users to the Enquiry page.

### About Us Page

File: about.html

The About Us page provides information about the history of DMS Plumbing, its establishment, experience and approach to providing plumbing services.

### Services Page

File: services.html

The Services page provides information about the different plumbing services offered by DMS Plumbing. These include general plumbing maintenance, burst pipe repairs, geyser services, leak detection, drain services, heat pumps and gas geyser installations.

### Enquiry Page

File: enquiry.html

The Enquiry page contains a form that allows users to provide their details and enquire about a specific plumbing service.

The form includes:

- Full name
- Phone number
- Email address
- Service required
- Description of the plumbing problem
- Submit button

### Contact Page

File: contact.html

The Contact page provides DMS Plumbing's contact information, office locations and links to the locations on Google Maps. It also contains a contact form.
