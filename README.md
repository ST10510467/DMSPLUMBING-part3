## Project Overview

This project is a website developed for DMS Plumbing. The purpose of the website is to provide customers with information about the company, its plumbing services, contact details and enquiry options.

The website was developed using HTML, CSS and JavaScript. It has a simple layout that helps customers find information and contact the company easily.

## Goal and Objectives

The main goal is to create a modern, trustworthy and mobile-friendly website that helps customers find the correct plumbing service and contact DMS Plumbing.

The objectives are to:

- Make it easier for customers to request quotes.
- Make emergency contact information easy to find.
- Help customers understand the different plumbing services.
- Improve the website's visibility on search engines.
- Provide clear information about the company and its services.

## Key Features and Functionality

The website includes:

- A homepage with information about DMS Plumbing.
- Navigation links to all five website pages.
- A services section with different plumbing services.
- A service search feature.
- A category filter to help customers find services.
- Service sorting from A to Z and Z to A.
- An FAQ section where customers can open and close questions.
- Enquiry and contact forms.
- Click-to-call emergency contact functionality.
- Images and a consistent website design.
- Responsive styling for different screen sizes.

## Organisation

DMS Plumbing is an owner-managed plumbing company established in 1999. The company provides plumbing services to residential, commercial, retail and hospitality customers.

DMS Plumbing also provides emergency plumbing services 24 hours a day, 7 days a week.

## Website Pages

The website consists of five main pages:

1. Home
2. About Us
3. Services
4. Enquiry
5. Contact

### Home Page

**File:** `index.html`

The Home page introduces DMS Plumbing and provides information about the company, its services and emergency plumbing assistance. It also includes a button that directs customers to the Enquiry page.

The page includes a Frequently Asked Questions section.

### About Us Page

**File:** `about.html`

The About Us page provides information about the history of DMS Plumbing, its establishment and its approach to providing plumbing services.

### Services Page

**File:** `services.html`

The Services page provides information about the different plumbing services offered by DMS Plumbing.

Customers can search for services, filter them by category and arrange them alphabetically.

### Enquiry Page

**File:** `enquiry.html`

The Enquiry page contains a form that allows customers to provide their details and enquire about a plumbing service.

The form includes:

- Full name
- Phone number
- Email address
- Service required
- Description of the plumbing problem
- Submit button

### Contact Page

**File:** `contact.html`

The Contact page provides DMS Plumbing's contact information, office locations and links to the locations on Google Maps. It also contains a contact form.

## Part 3 Improvements

The website was improved by adding extra functionality using JavaScript and improving the existing website features.

The following improvements were made:

1. Added a service search feature so customers can find plumbing services more easily.
2. Added category filtering for general plumbing and specialist services.
3. Added sorting options to arrange services from A to Z or Z to A.
4. Added an FAQ accordion that allows customers to open and close questions.
5. Used JavaScript to display and update service information based on customer searches and selections.
6. Improved the wording of service descriptions to make them easier for customers to understand.
7. Improved the website's search engine information using page titles, meta descriptions and image descriptions.
